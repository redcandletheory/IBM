# IBM i DCM Return Code & ADMIN3 Log Diagnostic Analyzer — Technical Guide

### Target Environment: **Integrated Application Server (IAS) / WebSphere Liberty on IBM i (V7R3, V7R4, V7R5, V7R6)**
* **Application Package**: `dcm-service.war`
* **Default Context Root**: `/dcm-service`
* **Repository**: `https://github.com/redcandletheory/IBM.git`

---

## 1. Overview & Purpose

This application provides diagnostic analysis for IBM i administrators, systems engineers, and application developers troubleshooting TLS/SSL and Digital Certificate Manager (DCM) operations on IBM i.

It provides two core, verified capabilities:
1. **ADMIN3 / Liberty `SystemOut.log` Trace Analyzer & EBCDIC CP037 Hex Decoder**:
   - Parses multi-line Java Native Interface (JNI) trace logs generated by WebSphere Liberty (`ADMIN3` instance) when managing certificates.
   - Decodes hexadecimal EBCDIC Code Page 037 (`CP037`) parameter byte streams in-place into human-readable IFS paths (e.g. `/QIBM/UserData/ICSS/Cert/Server/DEFAULT.KDB`) and certificate flags (`HASPRIVATEKEY`, `ALL_KEYS`, `TRUSTED`).
2. **IBM i GSKit (Global Security Kit) SSL/TLS Return Code Lookup**:
   - Looks up official return codes defined in IBM i header `QSYSINC/H(GSKSSL)` and `/QIBM/include/gskssl.h` (e.g., `GSK_OK` = 0, `GSK_ERROR_IO` = 406, `GSK_AS400_ERROR_NOT_TRUSTED` = 6000, `GSK_AS400_ERROR_NO_DEFAULT_CERT` = 6019).

## 2. Verified IBM i System Objects & IFS Locations

Every path, service program, header, and command documented here is part of the standard IBM i operating system:

### A. Real IBM i GSKit C Header & Service Program
* **C Header Member**: `QSYSINC/H(GSKSSL)`
* **IFS Header Path**: `/QIBM/include/gskssl.h`
* **Licensed Program**: `5770-SS1` Option 13 (*System Openness Includes*)
* **Runtime Service Program**: `QSYS/QFLAGSK` (bound to programs using TLS APIs via `QSYS/QUSAPIBD`)
* **How to Verify on IBM i**:
  ```cl
  DSPF STMF('/QIBM/include/gskssl.h')
  DSPOBJD OBJ(QSYS/QFLAGSK) OBJTYPE(*SRVPGM)
  ```

### B. Real Digital Certificate Manager (DCM) IFS Files
* **System Certificate Store**: `/QIBM/UserData/ICSS/Cert/Server/DEFAULT.KDB`
* **System Password Stash File**: `/QIBM/UserData/ICSS/Cert/Server/DEFAULT.STH`
* **Local Certificate Authority Store**: `/QIBM/UserData/ICSS/Cert/CertAuth/DEFAULT.KDB`
* **Local CA Password Stash File**: `/QIBM/UserData/ICSS/Cert/CertAuth/DEFAULT.STH`
* **How to Verify on IBM i**:
  ```cl
  WRKLNK OBJ('/QIBM/UserData/ICSS/Cert/Server/*')
  WRKAUT OBJ('/QIBM/UserData/ICSS/Cert/Server/DEFAULT.KDB')
  ```

### C. Real ADMIN3 WebSphere Liberty Server Logs
* **Liberty Server Root**: `/www/ADMIN3/wlp/usr/servers/admin/` (or `/www/ADMIN3/wlp/usr/servers/ADMIN3/`)
* **Trace & Output Logs**:
  - `/www/ADMIN3/wlp/usr/servers/admin/logs/SystemOut.log`
  - `/www/ADMIN3/wlp/usr/servers/admin/logs/messages.log`
* **Subsystem**: `QHTTPSVR`
* **Jobs**: `ADMIN3`, `ADMIN`
* **How to Verify on IBM i**:
  ```cl
  WRKACTJOB SBS(QHTTPSVR)
  DSPF STMF('/www/ADMIN3/wlp/usr/servers/admin/logs/messages.log')
  ```

## 5. Verified IBM i Diagnostic Verification Commands

To verify authorities, objects, and services on IBM i:

```cl
/* 1. Verify existence of Key Database and Password Stash */
WRKLNK OBJ('/QIBM/UserData/ICSS/Cert/Server/*')

/* 2. Check and grant IFS authorities to HTTP/DCM runtime profile (QTMHHTTP) */
WRKAUT OBJ('/QIBM/UserData/ICSS/Cert/Server/DEFAULT.KDB')
CHGAUT OBJ('/QIBM/UserData/ICSS/Cert/Server/DEFAULT.KDB') USER(QTMHHTTP) DTAAUT(*RWX) OBJAUT(*ALL)
CHGAUT OBJ('/QIBM/UserData/ICSS/Cert/Server/DEFAULT.STH') USER(QTMHHTTP) DTAAUT(*RWX) OBJAUT(*ALL)

/* 3. Check registered Application IDs */
WRKREGINF

/* 4. Check active HTTP and ADMIN server jobs in QHTTPSVR */
WRKACTJOB SBS(QHTTPSVR)

/* 5. Start IBM Administration Server instance (*ADMIN) */
STRTCPSVR SERVER(*HTTP) HTTPSVR(*ADMIN)

/* 6. Display official GSKSSL C header member */
DSPF STMF('/QIBM/include/gskssl.h')
```

## 6. How to Deploy `dcm-service.war` on IBM i

### Option A: Dropin Deployment (Integrated Application Server / Liberty)
1. Transfer `dcm-service.war` to `/tmp/dcm-service.war` on IBM i (binary transfer).
2. Copy to the server dropins directory:
   ```cl
   CPY OBJ('/tmp/dcm-service.war') +
       TODIR('/www/<instance>/wlp/usr/servers/<instance>/dropins') +
       REPLACE(*YES)
   ```
3. Access at `http://<YOUR_IBMI_HOST>:<PORT>/dcm-service/`.

### Option B: IBM Web Administration for i GUI
1. Open browser: `http://<YOUR_IBMI_HOST>:2001/HTTPAdmin`
2. Navigate to **Manage** &rarr; **Application Servers** &rarr; select `<instance>`.
3. Under **Server Tasks**, click **Install New Application**.
4. Select `dcm-service.war`, set context root to `/dcm-service`, and click **Finish**.
