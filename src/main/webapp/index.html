IBM i IWS 3.0 Web Service

This web service is running inside the IBM i Integrated Web Services (IWS 3.0 / Liberty profile) container.

Portable across IBM i V7R5 and IBM i V7R6.

Endpoints:

  • GET /api/status - Health & system diagnostics
  • POST /api/program/call?lib=...&pgm=... - Execute native IBM i programs
