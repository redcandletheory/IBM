IBM i DCM Symptom String & Return Code Search

Running on IBM i IWS 3.0 (Liberty Profile) • Portable across V7R5 / V7R6

Quick Test Examples:
DCM Reason Code Formula: Point of Failure = xxxyyyyzz
• xxx (Major Value): Entry Point in Service Program Manager Module (multiples of 1,000,000)
• yyyy (Utility Value): Point of failure in Utility Function (defined in qycuutl.H)
• zz (Minor Value): Local point of failure inside the Service Program Manager module

REST API Available: POST api/dcm/search or GET api/dcm/decode?symptom=...
